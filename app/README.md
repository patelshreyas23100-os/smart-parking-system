# Park Smart - Mobile App

This is the Flutter frontend for the Park Smart system.

## How to Run:

1.  **Start the Backend First**:
    Refer to the [RUNNING.md](file:///c:/Users/gunjan%20patel/OneDrive/Desktop/flutter_smart_park/RUNNING.md) in the root folder to start the FastAPI server.

2.  **Run the Flutter App**:
    ```powershell
    cd app
    flutter pub get
    flutter run
    ```

## Admin Panel:
- URL: [http://127.0.0.1:8001/admin/index.html](http://127.0.0.1:8001/admin/index.html)
- Requires the backend server to be running.
